# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

Thank you for considering contributing to the Simple Interest Calculator project! Here are guidelines to help you get started:

### Reporting Bugs

If you find a bug or unexpected behavior:
1. Check the existing Issues to see if it has already been reported.
2. If not, open a new Issue clearly describing the problem, steps to reproduce, and expected versus actual behavior.

### Suggesting Enhancements

Feature requests and improvements are always appreciated:
1. Open an Issue outlining your proposal and why it would be beneficial.
2. Provide examples or mockups where applicable.

### Submitting Pull Requests

1. **Fork the Repository**: Fork the repository to your own GitHub account.
2. **Clone the Fork**:
   ```bash
   git clone https://github.com/<your-username>/simple-interest-calculator.git
   cd simple-interest-calculator
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   # or for bug fixes:
   git checkout -b bug-fix-description
   ```
4. **Make Your Changes**: Write clean, readable Bash code or documentation updates.
5. **Test Your Changes**: Verify that `./simple-interest.sh` executes properly with various input values.
6. **Commit Your Changes**: Use clear and descriptive commit messages.
   ```bash
   git add .
   git commit -m "Add descriptive commit message"
   ```
7. **Push to Your Fork**:
   ```bash
   git push origin feature/your-feature-name
   ```
8. **Open a Pull Request**: Submit a Pull Request to the `main` branch with a concise description of your changes.

## Code Style & Standards

- Follow standard Bash scripting conventions.
- Keep documentation up to date with any script changes.
- Adhere to the [Code of Conduct](CODE_OF_CONDUCT.md).
